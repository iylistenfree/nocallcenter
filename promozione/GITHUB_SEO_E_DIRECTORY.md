## 2. Inserimento su AlternativeTo.net (Canale fondamentale!)

**AlternativeTo** è il sito di riferimento mondiale per chi cerca alternative a software commerciali. Quando qualcuno cerca su Google:
> *"Truecaller alternative open source"* oppure *"Alternative a Truecaller senza tracciamento"*

il primo risultato su Google è quasi sempre la pagina di AlternativeTo.

### Come inserire NoCallCenter:
1. Vai su https://alternativeto.net/
2. Crea un account gratuito (o accedi con GitHub).
3. Clicca su **"Add an application"** (in alto a destra o nel footer).
4. Compila i campi:
   - **Name:** `NoCallCenter`
   - **Platform:** `Android`
   - **License:** `Open Source (MIT License)`
   - **Website / URL:** `https://github.com/iylistenfree/nocallcenter`
   - **Download URL:** `https://github.com/iylistenfree/nocallcenter/releases/latest`
   - **Source Code URL:** `https://github.com/iylistenfree/nocallcenter`
   - **Short Description:** `A privacy-first, 100% on-device Android call blocker that uses a smart SMS-to-WhatsApp filter to defeat robocalls and spam.`
   - **Tag/Alternative to:** Aggiungi come alternativa a: `Truecaller`, `Hiya`, `Should I Answer?`, `Whoscall`.

## 3. Proposta per Liste "Awesome" su GitHub

Le liste "Awesome" sono repository con decine di migliaia di stelle seguiti da appassionati di privacy e software open-source. Basta aprire una Pull Request aggiungendo una riga nel loro README:

### A. Awesome Privacy (`pluja/awesome-privacy`)
- **Repo:** https://github.com/pluja/awesome-privacy
- **Sezione:** *Android* o *Communication / Phone*
- **Formato riga da proporre:**
  ```markdown
  - [NoCallCenter](https://github.com/iylistenfree/nocallcenter) - Lightweight, 100% on-device Android call blocker that filters spam calls without uploading user contacts. (MIT)
  ```

### B. Awesome Android Open Source (`Android-FOSS`)
- **Repo:** https://github.com/offa/android-foss
- **Sezione:** *Utilities* o *Security / Privacy*
- **Formato riga da proporre:**
  ```markdown
  - [NoCallCenter](https://github.com/iylistenfree/nocallcenter) - Privacy-first call screening app with WhatsApp human verification filter.
  ```

In Italia ci sono diversi gruppi e canali Telegram seguiti da decine di migliaia di appassionati di FOSS, Linux e Android a cui piace segnalare nuove app italiane:
